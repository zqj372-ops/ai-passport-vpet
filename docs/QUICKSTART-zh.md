# AI Passport 整机路线（买 → 用 → 刷 → 恢复）

决定不自己焊、直接用官方整机时的操作手册。官方资料：
<https://ai-passport.folotoy.cn/>

---

## 1. 购买

- 官网首页（或任意页面右上角）点 **「立即购买 / 选择购买平台」**：<https://ai-passport.folotoy.cn/>
- 当前价格：**¥99 标准版**（页面标注，最终以购买页为准）
- 页面另有「加入社群」入口，渠道有变化时可以问官方

到手配件：AI Passport 本体、USB-C 数据线（**必须是能传数据的线**，纯充电线刷不了机）。

## 2. 开箱就能用（不用电脑）

| 操作 | 说明 |
| --- | --- |
| 开机 | 按住左侧电源键 **0.5 秒** |
| 息屏唤醒 | 无操作一段时间自动息屏，按右侧任意功能键唤醒 |
| 关机 | 长按电源键 **2 秒** |
| 充电 | USB-C 接充电器或电脑；指示灯绿色常亮=充电中，熄灭=充满（**屏幕上不显示充电状态**） |
| 三枚功能键 | 右侧 上 / 下 / 确定 |

出厂固件已内置身份卡玩法 + 一款小游戏：主界面用上下键选「游戏」磁贴，按确定进入；
游戏里上下键控制、短按确定操作、长按确定退出。

## 3. 官方 App（微信小程序 / App）

手机开蓝牙 → 打开官方应用程序 → 附近设备里选你的 AI Passport → 同步：

- 名称
- 头像
- 一句自我介绍
- 一张全屏图片

这些内容通过**本地蓝牙**传输，不上传服务器。

## 4. 刷固件：两条路

> 共同前提：Chrome 或 Edge 最新版 + 支持数据传输的 USB-C 线 + 设备开机后连接电脑。

### 4.1 装官方小游戏（玩法库）

1. 打开玩法库：<https://ai-passport.folotoy.cn/plays/>
2. 进入想玩的玩法详情页 → 点「在线安装玩法」
3. 「连接设备」→ 浏览器弹窗里选串口
4. 核对名称/版本/来源 → 安装 → 校验 → 设备重启

⚠️ 安装官方玩法会**覆盖设备当前的全部内容**（现有存档/资料会丢）。

### 4.2 刷本地固件（自制 / 社区固件）

工具：<https://ai-passport.folotoy.cn/tools/web-flasher/>

1. **连接设备**：Type-C 线连电脑并开机 → 点「连接设备」→ 选择名称含
   `USB JTAG/serial debug unit` 的串口（不要选蓝牙/耳机）
2. **选择本地固件**：支持单个合并固件或多个分区 `.bin`，最多 8 个文件；**文件不上传服务器**
3. **写入设置**：波特率可选 115200 / 230400 / 460800 / 921600 → 「开始写入」
4. 写入完成后校验并重启

注意：

- **不要勾选「清除设备数据」**，除非你确实想抹掉设备上的全部数据。
- 过程中不要拔线、不要关闭或刷新页面。
- 连接失败时：换数据线、关掉占用串口的软件（串口监视器 / IDE），或只插一台设备再重试。

### 4.3 直接刷我们编好的「虚拟宠物」固件

本目录已经编译好（ESP-IDF v5.5.3，2026-09-10）：

| 文件 | 内容 | 大小 |
| --- | --- | --- |
| `artifacts/vpet-full.bin` | **数码暴龙机风格养成固件（中文界面 + 进化动画 + 双机 BLE 对战，推荐）** | 1,134,976 B |
| `artifacts/tamagezi-full.bin` | 虚拟宠物固件（12 只宠物、养育/训练/打工/商店/存档/音效） | 780,704 B |
| `artifacts/baseline-full.bin` | 官方硬件菜单基线固件 | 1,579,296 B |

用法：打开 web flasher → 连接设备 → 「选择 .bin 文件」选 `artifacts/tamagezi-full.bin`
→ 开始写入 → 等校验通过、设备重启。

操作方式：UP/DOWN 移动，短按 OK 选择/确认，长按 OK 返回；在主界面长按 OK 循环切换静音/音量档位。

### 4.4 数码暴龙机固件（`artifacts/vpet-full.bin`）

自研固件，机制对齐经典暴龙机，形象为原创像素怪兽（不包含任何官方角色美术）。

| 项目 | 内容 |
| --- | --- |
| 怪兽 | 31 种原创怪兽、7 个阶段：蛋 → 幼年期I → 幼年期II → 成长期 → 成熟期 → 完全体 → 究极体 |
| 进化 | 由年龄、训练次数、胜场、对战次数、照顾失误、体重共同决定；多分支 + 兜底分支，还有"养歪了"的失败线（暗影仔 → 泥浆兽 → 傀儡兽） |
| 进化动画 | 老形态/新形态快速闪烁变身 + 白光渐亮 + 结果亮相，按确定键可跳过 |
| 养成 | 饥饿心/力量心各 4 格、体重、便便、生病、睡眠与关灯、照顾失误计数 |
| 训练 | 3 轮「力量蓄力」小游戏（停在绿区得分），影响力量与体重 |
| 对战 | 先玩蓄力小游戏提升战力，再与同阶段 CPU 对手自动对战，有胜率记录 |
| 联机对战 | 菜单 `LINK`：两台都玩一次蓄力小游戏后进入 20 秒搜索（BLE 广播+扫描，无需配对），找到即开打；两台屏幕上的战斗过程与胜负完全一致 |
| 存档 | NVS 双槽 + CRC，掉电不丢 |
| 音效 | 进食/训练/命中/胜利/失败/进化/死亡等合成音 |
| 时间倍率 | 1 真实分钟 = 10 宠物分钟（1 宠物日约 2.4 小时），改 `VPET_TIME_SCALE` 可调 |
| 界面语言 | 中文（内嵌 Noto Sans CJK SC 子集字库,OFL 许可,274 个字形,约 36 KB） |

中文字库是**按需子集**:脚本会扫描源码字符串字面量,只把真正用到的 241 个汉字
(加上 ASCII)打进固件,所以体积可控。要改文案后重新生成:

```bash
tools/build_vpet_font.sh          # 需要 node + python3(+fontTools),约 4 秒
```

改完怪兽表想检查进化条件,可以打印整棵树(含失误上下限):

```bash
cc -std=c11 -Ifirmware-baseline/main tools/print_evolution_tree.c \
   firmware-baseline/main/vpet_species.c -o /tmp/vpet_tree && /tmp/vpet_tree
```

双机对战怎么用：

1. 两台设备都进入 `LINK`（各自先玩 3 轮蓄力小游戏）
2. 两台设备靠近（1 米内），屏幕显示 `SEARCHING FOR PARTNER...`
3. 找到对手后自动开打：左边是"你"、右边是对手，逐回合显示招式和伤害
4. 结果两台一致（同一组战斗卡 + 同一个种子，各自独立算出同一场），按 OK 可快进，长按 OK 退出

每台设备各自消耗 1 颗力量心、各自记胜负；找不到对手会在 20 秒后超时返回。

源码：`firmware-baseline/` 的 `feature/vpet` 分支（`main/vpet_*.c`），另有主机端单元测试
`tests/test_vpet_model.c`（`./tools/validate.sh --static` 会自动跑）。

## 5. 恢复出厂固件（玩坏了就靠这个）

官方教程：<https://ai-passport.folotoy.cn/guides/restore-factory-firmware/>

1. 用手机相机扫**你自己设备背面**的二维码（不要扫教程里的示意图），打开设备专属页面
2. 在页面底部「恢复固件」区域点「复制设备链接到电脑」，把完整链接发到自己电脑
   （链接含本机 SN 与 KEY，**不要公开分享**），用桌面版 Chrome/Edge 打开
3. Type-C 线连接设备并开机
4. 页面底部点「恢复默认固件」→「连接并核对设备」→ 选 `USB JTAG/serial debug unit` 串口
   → 勾选确认项 →「执行完整恢复」
5. 等待下载、校验、写入；设备自动重启并提示完成后再拔线

## 6. 关于「对战」的现实情况

- AI Passport 的 NFC 是**被动 NTAG213 标签**（只能被手机读），MCU 拿不到，不能用于对战。
- 两台 AI Passport 对战要靠 **BLE**（ESP32-C3 自带 BLE 5 LE）。官方玩法里目前的对战类内容有限，
  社区固件（如 `demo/claude-buddy-port`）有加密 BLE 通信的完整参考。
- 数码暴龙机式的「碰一碰」体验，如果要保留，需要自己加主动 NFC 模块或改成 BLE 握手。
